Wifi Mancer

Native macOS network visibility.
This experimental installer places Wifi Mancer in /Applications. Personal builds also need the reviewed helper installer to establish the exact client-signature pin. See the repository README.

  • App  ·  native SwiftUI interface
  • Helper  ·  loaded as a system LaunchDaemon, idle until used
  • Network access  ·  discovery is local; speed tests and optional tools may contact external services
  • Permissions  ·  administrator approval for helper installation and signature-pin updates
