Wifi Mancer is in /Applications. This does not confirm helper authentication. Follow the repository README to install the helper's exact client-signature pin, then verify Connected in Settings.

First three minutes:

  1. Launch Wifi Mancer from Launchpad or /Applications.
  2. Approve Location Services when prompted — macOS hides Wi-Fi names from apps without it. Wifi Mancer never reads your location.
  3. Open the Lobby. Drag a device left to Trust, right to request IPv4 targeting. A targeted device is not proof of complete Internet blocking.

Re-run onboarding any time from Settings  ›  About.
